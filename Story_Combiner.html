Authentication note

The redirect URI must be registered on the OAuth application. The default arcgisstorymaps client belongs to StoryMaps and will reject this local tool's URL. Create or use an ArcGIS OAuth application that allows this exact redirect URI, then enter its client ID above. Serving this file from a local HTTP server is more reliable than opening it as file://.

Detailed: create the OAuth user-login item
  1. Serve this file locally, if needed: python3 -m http.server 8000 from its folder, then open http://localhost:8000/sidecar-consolidator.html.
  2. Sign in to the target ArcGIS Online or ArcGIS Enterprise portal with an account allowed to create developer credentials.
  3. Open Content → My content → New item → Developer credentials.
  4. Select OAuth 2.0 credentials, then choose the user-authentication/browser application environment when prompted.
  5. For Redirect URLs, add the exact URL where this file is running. For the local example, use http://localhost:8000/sidecar-consolidator.html. Click Add.
  6. Give the credential item a recognizable title, such as StoryMaps Sidecar Consolidator, and create/save it.
  7. Open the new credential item and copy its Client ID into this tool’s OAuth client ID field. This browser-only flow does not need a client secret; never paste a client secret into this HTML.
  8. Set the tool’s Portal host to the same portal that owns the credential item, and make sure the redirect URI field matches the registered value character-for-character.
  9. Click Sign in with ArcGIS, approve the login, then enter one or more Story item IDs and click Load draft story.

If the portal does not show Developer credentials, the account or organization may not have the required privilege. Use the organization’s approved developer-credential workflow or ask an administrator.
